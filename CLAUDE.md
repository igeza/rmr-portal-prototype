# Prototype Guidelines

This project is a UX/UI prototype, not production software.

## Priorities
1. Visual fidelity
2. Functional interactions
3. Fast iteration
4. Simple implementation

## Rules
- Reuse existing components whenever possible.
- Use mock/local data.
- Do not add dependencies unless necessary.
- Do not refactor unrelated code.
- Keep changes scoped to the requested feature.
- Don't modify files unrelated to the task.
- Prefer simple implementations over production-level architecture.
- Don't spend time optimizing code that isn't relevant to the prototype.
- Keep final responses concise.
