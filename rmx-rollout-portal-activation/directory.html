rmResident Portal Rollout

Rollout flow for existing TWA users: from the dashboard announcement, through conversion setup and the checklist, to activating rmResident Portal. Start at screen 1 and click through, or open any state from the list.

Reset walkthrough — clears what has been started, marked Ready or activated. Progress is otherwise remembered between visits.

  • 1. Dashboard

    Existing TWA user’s My Workspace with the new rmResident Portal announcement. Start here — “Learn More” opens the announcement.

  • 2. Announcement — Learn More

    The “rmResident Portal is here” overlay. “Go to Administration” continues the flow.

  • 3. Administration — Get started

    rmResident Portal section with the “New rmResident Portal is now available” banner. “Get Started” opens the Activate chooser.

  • 4. Administration — Conversion started

    Setup banner at 33% with the four portal settings. “View My Checklist” opens the checklist.

  • 5. Setup guide (Guided Setup stepper; replaces the checklist)

    New Portal Setup overlay at 0% with What’s new and Notify your residents expanded. Items turn Ready for real as you complete them.

  • 6. Checklist — In progress

    33% complete, single Default profile. Designed state; the live checklist is screen 5.

  • 7. Checklist — Multiple locations

    Two locations (Default and Blooming Floral Co.). Designed state with two locations.

  • 8. Checklist — Ready to activate

    All items Ready, with the “Ready to go live?” banner. “Activate rmResident Portal” opens the confirmation.

  • 9. Confirm Activation

    Pop Up for accounts with multiple locations (retires TWA across all locations). “Activate” completes the rollout.

  • 9b. Confirm Activation — single location

    Variant copy for a single-location account. Reached from this list only.

  • 10. Administration — Ready to activate

    Setup banner at 100% (checklist closed once complete), with “Activate rmResident Portal”.

  • 11. Administration — Portal activated

    Banner gone, success Toast shown. End of flow.

  • 12. Administration — full menu

    Opened from the Mega Menu’s Administration tab. All 14 sections with their items; the left menu jumps to each section, and rmResident Portal opens screen 3.

  • 13. Tour — Welcome to rmResident Portal

    Opened from the tour icon beside “rmResident Portal” on any Administration page. Learn More continues through Why use it?, What can residents do?, and Preview before Publishing; Finish or X returns to where you started.

  • 14. Portal Profiles register

    Opened from Portal Profiles in Administration. Profile actions (Make Default, Make Inactive / Active) work from each row’s menu.

  • 15. Profile Details — Portal Branding

    Opened by Review on a profile in the checklist. Edit profile, assign property types, reassignment warnings, Portal Preview, Save Draft and Publish all work. Publish marks the profile Ready and returns to the checklist.

  • 16. Profile Details — Portal Settings

    Second tab of the same profile. Page Settings and Account Management are not designed yet.

  • 17. User — Privileges

    The new rmResident Portal privileges (Manage Portal Profiles, Portal Log-In, Payment Policies, App Settings). Reached from this list only.

  • 19. Payment Policies register

    Opened from Payment Policies in Administration. Row click or Add Policy Settings opens Payment Policy Details (settings update the preview live); Make Default / Make Inactive work from each row’s menu.

  • 20. Payment Policy Details — from setup checklist

    Opened by Review on a policy in the checklist: the Payment Policy Details overlay opens over the checklist. Ready to Publish closes the overlay and the policy’s row turns Ready; Cancel or X closes without changes.

  • 18. Portal Customization tour

    Opened from the info icon in the Portal Profiles context bar. Welcome → Custom Portal for Each Property Type → Add Your Brand Identity → Control Exactly Which Pages Tenants Can Access → Take Control of Account Settings → Publish When You’re Ready.
